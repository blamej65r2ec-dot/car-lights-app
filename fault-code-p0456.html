P0456: Evaporative Emission System Leak Detected (Very Small Leak)

Caution

What does P0456 mean?

The fuel vapor system has a very small leak. The code is stored when the computer detects the problem, and it usually turns on the check engine light.

What causes P0456?

  • Worn fuel cap seal
  • Pinhole in a hose or the filler neck
  • Faulty valve

How do I fix P0456?

  1. Replace the fuel cap
  2. Have the system smoke tested

Can I keep driving with P0456?

Usually yes for a short time, but get it checked soon. Stop if the car shakes, loses power or the check engine light flashes.

How much does it cost to fix?

From $15 for a cap to about $150 for a smoke test. These are rough US ranges and vary by car and shop.
