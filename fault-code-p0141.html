P0141: O2 Sensor Heater Circuit (Bank 1 Sensor 2)

Caution

What does P0141 mean?

The heater in the downstream oxygen sensor is not working. The code is stored when the computer detects the problem, and it usually turns on the check engine light.

What causes P0141?

  • Faulty oxygen sensor
  • Blown fuse
  • Wiring fault

How do I fix P0141?

  1. Check the fuse
  2. Check the wiring
  3. Replace the oxygen sensor

Can I keep driving with P0141?

Usually yes for a short time, but get it checked soon. Stop if the car shakes, loses power or the check engine light flashes.

How much does it cost to fix?

An oxygen sensor is roughly $150 to $400 fitted. These are rough US ranges and vary by car and shop.
