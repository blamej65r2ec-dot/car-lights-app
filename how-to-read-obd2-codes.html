How to Read OBD-II Fault Codes

A fault code tells you where the car found a problem.

How to read a code

  1. Find the OBD-II port, usually under the dashboard near the steering column.
  2. Plug in a scanner and switch the ignition on.
  3. Read and write down the code, for example P0420.
  4. Look the code up before you clear it or replace any parts.

What the letters mean

  • P: powertrain (engine and transmission)
  • B: body (airbags, doors, seats)
  • C: chassis (brakes, steering, suspension)
  • U: network (communication between modules)

The digits narrow down the system and the exact fault. A code points to a problem area, not always to one broken part.
