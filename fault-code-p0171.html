P0171: System Too Lean (Bank 1)

Caution

What does P0171 mean?

The engine is getting too much air or too little fuel. The code is stored when the computer detects the problem, and it usually turns on the check engine light.

What causes P0171?

  • Vacuum leak
  • Dirty mass airflow sensor
  • Weak fuel pump or clogged filter
  • Faulty oxygen sensor
  • Leaking intake gasket

How do I fix P0171?

  1. Check hoses and the intake for leaks
  2. Clean the mass airflow sensor with sensor cleaner
  3. Check fuel pressure
  4. Replace the oxygen sensor if it tests bad

Can I keep driving with P0171?

Usually yes for a short time, but get it checked soon. Stop if the car shakes, loses power or the check engine light flashes.

How much does it cost to fix?

A sensor clean is about $10. A fuel pump is roughly $400 to $1,000 fitted. A vacuum hose is cheap. These are rough US ranges and vary by car and shop.
